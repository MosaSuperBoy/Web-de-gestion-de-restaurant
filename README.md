# PLUTO RESTAU-JOMO

Site de présentation et de commande pour un restaurant de cuisine ivoirienne à Abidjan.

L’application est réalisée en HTML, CSS et JavaScript, sans dépendance de compilation. Pour les instructions d’utilisation et d’administration, consultez [LISEZ-MOI.md](./LISEZ-MOI.md).

## Déploiement GitHub Pages

Le site statique est publié automatiquement depuis la branche `main` avec GitHub Actions :

https://mosasuperboy.github.io/Web-de-gestion-de-restaurant/

**Limitation :** GitHub Pages n’exécute pas PHP. L’API de maintenance n’y est donc pas disponible et la boutique suspend les commandes par précaution. La carte reste consultable. Pour activer les commandes, déployez le projet sur un hébergeur compatible avec PHP et MySQL, puis configurez l’API de maintenance.
